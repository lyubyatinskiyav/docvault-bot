# DocVault bot

Телеграм-бот для учёта сроков документов и страховок.

## Render

1. [Render Dashboard](https://dashboard.render.com) → **New** → **Web Service** → репозиторий `docvault-bot`.
2. Runtime: Python. Build: `pip install -r requirements.txt`. Start: `python main.py`.
3. Environment → `BOT_TOKEN` = токен от [@BotFather](https://t.me/BotFather). Токен в GitHub не кладите.
4. Дождитесь зелёного статуса, в Telegram отправьте `/start`.
